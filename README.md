# TLT vs US 20Y & 30Y Yields (published copy)

Static web copy of `tlt-vs-20y/tlt_vs_20y.html`: TLT scenario calculator (duration model with iShares
duration/convexity), TLT and 20Y/30Y daily candles, scatter and rolling duration.
`ishares_history.csv` is the daily record of iShares' TLT effective duration and convexity.
Generated by `tlt-vs-20y/publish_site.py` on the source PC - do not edit here; every publish overwrites the files.
